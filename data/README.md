# Simulation datasets

Current versioned example datasets live in [simulation-v1/](simulation-v1/).
See its [README](simulation-v1/README.md) for generation, validation, evaluation,
and reproduction commands.

The four legacy CSVs previously stored directly in this directory were removed.
Use the versioned bundles for the current simulation workflow. Their resource
metrics are synthetic and do not demonstrate real Docker or eBPF performance.
